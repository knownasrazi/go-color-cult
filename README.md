# go-color-cult

> Go color cult - palette extraction and harmonious scales API.

**Colors, cult-grade Go.** — built for vibe coders who ship.

---

## Manifesto

Clean over chrome. Stone over shadow. This is a tool that gets out of your way.

> "Go color cult - palette extraction and harmonious scales API."

No onboarding. No dashboard. Just open and go.

## Stack

- Go (Go + color-go)
- Clean tokens: #fdfcfa / #ebe7e0 / #1a1a1a
- No tracking, no analytics by default

## Quick start

```bash
git clone https://github.com/knownasrazi/go-color-cult.git
cd go-color-cult
go run main.go
```
