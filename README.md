## Why go-color-cult?

> Colors, cult-grade Go. - built for vibe coders and web developers who ship with taste.

Go color cult - palette extraction and harmonious scales API. This template keeps the cream aesthetic - stone, ink, and low contrast - and ships with a clean structure you can vibe-code on top of.

## Stack

- **Language:** go
- **Style:** Tailwind cream tokens, Biome where applicable
- **Quality:** CI, lint, and a minimal test harness

## Get started

```bash
git clone https://github.com/knownasrazi/go-color-cult.git
cd go-color-cult
```
